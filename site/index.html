FIELD MANUAL — INSTALLING MODS

Check each version's framework constraint (shown per version) before installing. Always read the mod's own description — many list extra steps or dependencies, which the depot shows per version.

CLIENT MOD (BEPINEX)

  1. Use the archived file (LOCAL) or the recorded GitHub release.
  2. Extract into the game folder so the DLL lands in BepInEx/plugins/.
  3. Launch via the framework launcher; check the BepInEx log for load errors.

SERVER MOD

  1. Use the archived file (LOCAL) or the recorded GitHub release.
  2. Extract into user/mods/ — one folder per mod containing package.json.
  3. Restart the server; watch the console for the mod's load line.

GENERAL RULES

  • Match the version's constraint to your framework version (4.1.x) — mismatches are the top cause of breakage.
  • Back up user/profiles/ before installing.
  • Install dependencies first — the depot lists them per version.
